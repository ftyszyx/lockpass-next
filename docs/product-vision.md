# 产品愿景

LockPass Next 面向个人和家庭用户，核心价值是：在不把明文密码交给任何服务端的前提下，安全地保存、查找、同步和恢复密码。

当前阶段以桌面端为主，把日常使用体验和安全底座做好；开源服务器端和服务器后台作为同步基础设施同步建设。服务器只能保存密文和同步元数据，不能查看保险库明文。

## 核心场景

1. 第一次启动时登录服务器账号，并设置或输入用于解锁保险库的主密码。
2. 支持同一台设备切换多个服务器账号；每个账号在本机有独立加密缓存、条目和附件。
3. 保存登录密码、银行卡、证件、笔记、恢复码和一次性验证码种子。
4. 在桌面端快速搜索并复制账号、密码或一次性验证码。
5. 通过全局快捷键唤起快速搜索窗口。
6. 本地离线可用，联网后自动保存密文数据到服务器。
7. 支持备份、恢复、旧版 LockPass 导入和后续 schema 迁移。
8. 用户可以选择官方托管同步服务，也可以自己部署服务器。

## 产品边界

1. 桌面端是当前阶段主产品，目标覆盖 Windows、macOS 和 Linux；服务器端和服务器后台用于服务器账号、设备、保存状态与实例配置管理。
2. 服务器端不保存用户明文、主密码、vault key 或任何可解密密钥。
3. 当前阶段支持在同一台设备切换多个服务器账号，但不做多人共享保险库。
4. 当前阶段不做移动端、浏览器插件和系统级自动填充。
5. 付费点只能建立在托管服务、存储、设备数量、备份保留、同步便利性等服务能力上，不能破坏开源自部署和端到端加密。

## 首版桌面端能力

1. 首启登录服务器账号、主密码解锁、锁定、自动锁定。
2. 多服务器账号切换和独立本机加密缓存。
3. vault 和条目管理。
4. 登录密码、银行卡、安全笔记、恢复码等条目类型。
5. 密码生成器。
6. 快速搜索、复制、剪贴板自动清理。
7. 本地 SQLite 加密数据存储。
8. 安全密钥创建、离线保存提示和受信任设备上的系统安全存储；跨设备恢复闭环仍依赖后续同步协议实现。
9. 加密备份导入导出。
10. 旧版 LockPass 数据导入。

## 服务器端能力

1. 用户账户、邮箱验证码、设备登记和会话管理。服务器账号不使用保险库主密码登录；SMS、Google OAuth 和微信 OAuth 是预留入口，默认禁用，不能描述为已可用。
2. vault 保存状态、设备同步进度和密文对象状态。
3. 密文对象、revision、tombstone、冲突元数据和 `wrappedVaultKey` 记录存储；`wrappedVaultKey` / 新设备恢复仍按协议预留或待完成处理。
4. PostgreSQL 持久化。
5. Docker 化部署。
6. 官方托管服务所需的计费和配额扩展点。
